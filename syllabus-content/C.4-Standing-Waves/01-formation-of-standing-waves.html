Standing Waves in Strings
How two travelling waves create a stationary pattern of nodes and antinodes — and the physics behind every guitar string, piano wire, and violin.

Question to Ponder

Why does a guitar string seem to "freeze" into a shape with multiple motionless points when you lightly touch it at the 12th fret? And why does a jump rope form a loop that stays in one place instead of travelling along the rope?

The answer lies in the superposition of two identical waves travelling in opposite directions — producing a standing wave.

Fig 1 — Guitar strings vibrate in standing wave patterns. Pressing a fret changes the effective length L, changing the pitch. Lightly touching at the 12th fret forces a node at the midpoint, producing the second harmonic.
Core knowledge — how standing waves form

How a Standing Wave Forms

Imagine sending a wave pulse along a string towards a fixed end. When the pulse arrives, it reflects and returns inverted (flipped). Now picture a continuous wave: the original wave travels to the right while the reflected wave travels to the left. You have two identical waves moving in opposite directions.

These two waves interfere. At certain points, a crest from one wave always meets a trough from the other — they cancel permanently. These points of zero displacement are called nodes (N). At other points, a crest always meets a crest — they reinforce to maximum amplitude. These points are called antinodes (A).

The result is a wave pattern that does not travel — it simply vibrates up and down in place. This is a standing wave (or stationary wave).

Fig 2 — A pulse reflects off a fixed end and returns inverted. This is the starting point for understanding standing wave formation.
Fig 3 — Two identical waves travelling in opposite directions interfere to produce a standing wave. The resultant pattern does not move along the string.
💡 A standing wave stores energy — it does not transmit it. The energy oscillates between kinetic (at zero displacement) and elastic potential (at maximum displacement), but it stays in the same region of the string.

⚠️ Common mistake: "A standing wave doesn't move." The pattern doesn't move, but the particles of the string are oscillating up and down rapidly. Think of a Mexican wave in a stadium — the pattern moves, but each person only stands and sits.
The big relationship — harmonics on a string

Condition for Standing Waves on a String

A string fixed at both ends must have a node at each end. This means only certain wavelengths "fit" on the string. The length L must equal a whole number of half-wavelengths:

L = n · (λₙ / 2)   →   λₙ = 2L / n    (n = 1, 2, 3, …)

Here n is the harmonic number: n = 1 is the fundamental (first harmonic), n = 2 is the second harmonic, and so on.

From Wavelength to Frequency

The wave speed v on a string is fixed by the physical properties of the string (tension and mass density) — it does not change with harmonic number. Using v = fλ:

fₙ = v / λₙ = n · (v / 2L) = n · f₁

So the resonant frequencies are simply integer multiples of the fundamental: f₁, 2f₁, 3f₁, 4f₁, …

Wave Speed on a String

The speed of a transverse wave on a string depends on the tension T (in Newtons) and the linear mass density μ (in kg/m, where μ = mass / length):

v = √(T / μ)

Combining everything gives the master equation for standing waves on a string:

fₙ = (n / 2L) · √(T / μ)
Fig 5 — The first four harmonics on a string fixed at both ends. Notice: the harmonic number n equals the number of antinodes, and the number of nodes is always n + 1 (including the two fixed ends).

Proportionality Statements

From the master equation fₙ = (n / 2L) · √(T / μ), we can extract four key proportionalities:

RelationshipMeaningReal-world example
fₙ ∝ nHarmonics are equally spaced in frequencyOvertone series of any string instrument
fₙ ∝ √THigher tension → higher pitch (square-root relationship)Turning a tuning peg tightens the string
fₙ ∝ 1/LShorter string → higher pitchPressing a guitar fret shortens the vibrating length
fₙ ∝ 1/√μLighter string → higher pitchThin treble strings vs. thick bass strings
λₙ = 2L/n fₙ = n·f₁ v = √(T/μ) fₙ = (n/2L)·√(T/μ)
✓ Exam tip: When asked "what happens to f when T is doubled?", write: f ∝ √T, so f_new = √2 · f_old. The frequency increases by a factor of √2 ≈ 1.41 — it does NOT double.

Examiners test your understanding of standing waves through graphs. Each graph below linearises one of the proportionality relationships. A straight line through the origin confirms a directly proportional relationship.

Fig 6 — f vs n: a straight line through the origin. The gradient equals the fundamental frequency f₁. This confirms fₙ = n · f₁.

⚠️ Examiner's trap: If asked to plot the relationship between f and T, many students plot f vs T (which gives a curve). The linearised version is f vs √T. Similarly, f vs L gives a curve — linearise as f vs 1/L.
Worked example

Worked Example — Guitar String Frequencies

A guitar string of length 0.65 m has a mass of 2.6 g and is under a tension of 720 N. Calculate: (a) the wave speed, (b) the fundamental frequency, and (c) the frequency of the 3rd harmonic.

1
State the known values: L = 0.65 m, m = 2.6 g = 0.0026 kg, T = 720 N.
2
Calculate linear mass density: μ = m / L = 0.0026 kg / 0.65 m = 0.004 kg/m.
3
(a) Calculate wave speed: v = √(T / μ) = √(720 / 0.004) = √(180 000) = 424 m/s.
4
(b) Calculate fundamental frequency: f₁ = v / (2L) = 424.3 / (2 × 0.65) = 424.3 / 1.3 = 326 Hz.
5
(c) Calculate the 3rd harmonic: f₃ = 3 × f₁ = 3 × 326.4 = 979 Hz.
💡 Units check on v = √(T/μ): T is in kg·m/s² and μ is in kg/m. So T/μ = (kg·m/s²)/(kg/m) = m²/s², and √(m²/s²) = m/s ✓. Always convert grams to kilograms before calculating μ.
Real-world application — the piano

Bass Strings (Low Notes)

Bass strings on a piano are thick and wrapped in copper wire. This increases μ (linear mass density), which lowers the frequency without requiring the piano to be several metres long. Since f ∝ 1/√μ, a heavier string vibrates at a lower pitch for the same length and tension.

Treble Strings (High Notes)

Treble strings are thin and under high tension. Since f ∝ √T and f ∝ 1/√μ, a thin string under large tension produces a high frequency. This is why the rightmost strings on a piano are short, thin, and very taut.

Common misconceptions — trap corner

Misconceptions to Avoid

MisconceptionCorrect View
"Standing waves don't move"The pattern is stationary, but the string particles oscillate up and down at high speed. Energy is stored, not absent.
"All points have the same amplitude"Amplitude varies from zero (nodes) to maximum (antinodes). All points share the same frequency, but not the same amplitude.
"Energy disappears in a standing wave"Energy is stored in the oscillation (kinetic + elastic potential). It is not transmitted along the string, but it is very much present.
"Harmonics are separate waves"Harmonics are different modes of vibration that can coexist simultaneously on the same string. A guitar's rich tone comes from a mixture of f₁, f₂, f₃, …
✓ Phase rule: All points between two adjacent nodes vibrate in phase (same direction at the same time). Points in adjacent segments — separated by a node — are in antiphase (180° out of phase). This is a favourite exam question.

Exam-style questions
Exam question · Calculate & Determine
A guitar string of length 0.80 m vibrates in its fundamental mode with a frequency of 200 Hz.
(a) Calculate the wave speed on the string. [2 marks]
(b) The tension in the string is 150 N. Determine the linear mass density μ of the string. [2 marks]
(c) The string is now pressed at the midpoint (L = 0.40 m). State the new fundamental frequency. [1 mark]
(a) f₁ = v/(2L) → v = f₁ × 2L ✓
v = 200 × 2 × 0.80 = 320 m/s ✓

(b) v = √(T/μ) → μ = T/v² ✓
μ = 150 / (320)² = 150 / 102400 = 1.46 × 10⁻³ kg/m ✓

(c) f₁ ∝ 1/L. Halving L doubles f₁ → new f₁ = 400 Hz ✓
Exam question · State & Explain
A graph of fundamental frequency f against √T for a string of fixed length gives a straight line through the origin with a gradient of 20 Hz/√N.
(a) State the relationship between f and T shown by this graph. [1 mark]
(b) The string has a length of 0.50 m. Using the gradient, calculate the linear mass density μ. [3 marks]
(a) f is directly proportional to √T (or f ∝ √T). ✓

(b) Gradient = 1/(2L√μ) ✓
20 = 1/(2 × 0.50 × √μ) = 1/(1.0 × √μ) ✓
√μ = 1/20 = 0.05 → μ = (0.05)² = 2.5 × 10⁻³ kg/m ✓
Exam question · Explain
Explain how a standing wave is formed on a string that is fixed at both ends. In your answer, describe the role of reflection, superposition, and boundary conditions. [4 marks]
A travelling wave moves along the string and reflects at the fixed end ✓, returning inverted (phase change of π) ✓. The incident and reflected waves, which have the same frequency and amplitude, undergo superposition ✓. Because the ends are fixed, only wavelengths that produce nodes at both boundaries can persist — this is the boundary condition that selects the allowed harmonics (λₙ = 2L/n) ✓.
