Processing Uncertainties
Every reading you take carries a range of possible true values. This lesson shows how to state that range, carry it through a calculation, and round the final answer so it matches.

🎯 Hook – the meter that never quite agrees with itself

Read a moving-coil ammeter twice and the needle rarely settles on exactly the same mark. Read a digital multimeter twice and the last digit sometimes flickers between two values. Neither meter is broken — every measurement has an uncertainty, a range around the reading within which the true value is expected to lie.

Fig 1 — The needle sits at 1.6 mA, but it could reasonably be read as anywhere within half a scale division either side of that mark.
💡 Diagnostic question (think – then read on) — two students measure the same wire with the same metre rule. One writes "L = 12 cm". The other writes "L = 12.0 ± 0.1 cm". Which one has actually reported a measurement? Only the second. A number with no uncertainty tells you nothing about how far the true value could lie from 12 cm — it could really be 11 cm or 13 cm. Quoting ± 0.1 cm tells you the true length is expected to lie between 11.9 and 12.1 cm.

📖 What is uncertainty?

Uncertainty is a quantitative indication of the quality of a result. It is a range of values around a measurement within which the true value is expected to lie, and is an estimate. It is not the same thing as an error: an error arises from the equipment or the technique used and is the actual difference between the reading taken and the true value, whereas the uncertainty is the range you assign around a reading to allow for that possibility. Uncertainties in measurements are recorded as a range (±) to an appropriate level of precision.

Uncertainty……is taken as
in a reading± half the smallest scale division
in a measurementat least ± 1 smallest division
in repeated datahalf the range, i.e. ± ½ (largest − smallest value)
in a digital reading± the last significant digit (unless otherwise quoted)

🔢 Absolute, fractional and percentage uncertainty

Uncertainty is expressed in one of three forms. Take \(L = 5.0 \pm 0.1\) cm as the running example:

Absolute uncertainty — the actual amount by which the measurement is uncertain$$\Delta L = \pm 0.1\ \text{cm}$$
Fractional uncertainty — the uncertainty expressed as a fraction of the measurement$$\frac{\Delta L}{L} = \frac{0.1}{5.0} = \pm 0.02$$
Percentage uncertainty — the uncertainty expressed as a percentage$$\frac{\Delta L}{L}\times100 = \pm2\%$$

In general:

$$\%\ \text{uncertainty} = \frac{\text{uncertainty}}{\text{measured value}}\times100\%$$

✍️ Worked example 1 – reading an analogue meter

An analogue milliammeter is read as 1.6 mA. The smallest scale division is 0.2 mA. State the absolute, fractional and percentage uncertainty in this reading.

1
Identify: the uncertainty in a reading is ± half the smallest scale division.
2
Data: smallest division \(= 0.2\) mA, so absolute uncertainty \(= 0.2/2 = 0.1\) mA. Reading \(= 1.6 \pm 0.1\) mA.
3
Equation: fractional uncertainty \(= \dfrac{0.1}{1.6} = \dfrac{1}{16}\).
percentage uncertainty \(= \dfrac{0.1}{1.6}\times100 = 6.2\%\).
4
Answer: Reading \(= 1.6\ \text{mA} \pm \tfrac{1}{16}\), or equivalently \(1.6\ \text{mA} \pm 6\%\) (rounded from 6.2%).

⚖️ Propagating uncertainties in processed data

Uncertainty propagates through a calculation differently depending on the operation involved.

OperationExamplePropagation rule
Addition & subtraction\(y = a \pm b\)\(\Delta y = \Delta a + \Delta b\) — the sum of the absolute uncertainties
Multiplication & division\(y = ab\) or \(y = a/b\)\(\dfrac{\Delta y}{y} = \dfrac{\Delta a}{a} + \dfrac{\Delta b}{b}\) — the sum of the fractional uncertainties
Power\(y = a^{n}\)\(\dfrac{\Delta y}{y} = n\left(\dfrac{\Delta a}{a}\right)\) — \(n\) times the fractional uncertainty

In short: adding or subtracting measurements → add the absolute uncertainties. Multiplying or dividing measurements → add the percentage (or fractional) uncertainties. Measurements raised to a power → multiply the percentage uncertainty by the power.

🔗 The uncertainty in a constant, such as \(\pi\), is taken to be zero. Uncertainties in trigonometric and logarithmic functions are not tested in the IB exam.

✍️ Worked example 2 – percentage uncertainty in a mean value

A student obtains the following results in an experiment to determine the angular frequency \(\omega\) of a rotating disc. Calculate the percentage uncertainty in the mean value of \(\omega\).

Reading12345
\(\omega\) / rad s⁻¹0.1540.1530.1590.1470.152
1
Identify: uncertainty in repeated data is ± half the range; then \(\%\ \text{unc} = (\text{uncertainty}/\text{value})\times100\).
2
Data: mean \(\omega = \dfrac{0.154+0.153+0.159+0.147+0.152}{5} = 0.153\ \text{rad s}^{-1}\).
3
Equation: uncertainty in \(\omega = \tfrac12\times(0.159-0.147) = \pm0.006\ \text{rad s}^{-1}\).
4
Answer: \(\%\ \text{unc} = \dfrac{0.006}{0.153}\times100 = 3.92\% \approx 4\%\) (1 s.f.). So \(\omega = 0.153\ \text{rad s}^{-1} \pm 4\%\).
Fig 4 — The five \(\omega\) readings. The range runs from 0.147 to 0.159 rad s⁻¹, so half of it — 0.006 rad s⁻¹ — is the uncertainty in the mean.
🔍 The percentage uncertainty here can safely be rounded to 1 s.f. Working backwards, the absolute uncertainty implied by 4% is \(0.153\times0.04 = 0.00612\ \text{rad s}^{-1}\), which itself rounds to 0.006 rad s⁻¹ to 1 s.f. — exactly the value calculated directly, so no information is lost by the rounding.

🔬 Uncertainties and significant figures

Measurements and processed uncertainties must be expressed to an appropriate number of significant figures, because the number of significant figures indicates how precise a measurement is.

In an uncertainty: absolute, fractional and percentage uncertainties should usually be quoted to one significant figure. For example, for \(7.4 \pm 0.2\), the percentage uncertainty is \(\pm2.703\%\), so this is quoted as \(\pm3\%\) (1 s.f.). The main exception is when the first digit is 1 — then the uncertainty can be quoted to two significant figures. For example, for \(36.4652 \pm 5\%\), the absolute uncertainty is \(\pm1.82326\), so this is quoted as \(\pm1.8\) (2 s.f.).

In a quantity: the number of significant figures must match the precision of the absolute uncertainty — the quantity and its uncertainty are quoted to the same number of decimal places, and a final calculated value is rounded so its least significant digit aligns with the uncertainty's place value. For example, \(36.4652 \pm 5\%\) is finally quoted as \(36.5 \pm 1.8\).

In raw data: the number of significant figures should be consistent with the resolution of the measuring instrument.

InstrumentResolutionExample reading
Metre rule± 1 mm15 ± 1 mm
Vernier callipers± 0.1 mm15.4 ± 0.1 mm
Micrometer screw gauge± 0.01 mm15.42 ± 0.01 mm

In processed data: calculated values should have no more significant figures than the least precise measurement. For example, for the raw data 5.11, 5.14, 5.12, 5.10, the mean value is 5.1175, which should be quoted to 3 significant figures, i.e. 5.12.

✓ Examiner tip: absolute uncertainties (\(\Delta\)) carry the same units as the quantity; fractional and percentage uncertainties have no units. The uncertainty in a constant such as \(\pi\) is always taken to be zero.

🌍 Real-world: why manufacturers publish a tolerance, not a number

A resistor labelled "10 Ω ± 5%" tells you far more than "10 Ω" alone: it tells you the actual resistance of any resistor from that batch lies between 9.5 Ω and 10.5 Ω. Engineers, and IB examiners, routinely need to decide whether two measured values are genuinely different or whether they simply overlap once their uncertainty ranges are taken into account.

✓ Examiner tip: when a question asks you to compare two results, check whether their uncertainty ranges overlap. If they do, you cannot claim the results are different — say so explicitly.

🚀 HL Extension – propagating uncertainty through a multi-step formula

Real formulas often combine several operations at once — for example \(g = 4\pi^2 L / T^2\) for a simple pendulum. Since \(\pi\) is a constant, its uncertainty is zero, so \(4\pi^2\) is treated as an exact number; only \(L\) and \(T\) contribute uncertainty, and \(T\) enters as \(T^2\), so its percentage uncertainty is doubled by the power rule before the division rule combines it with \(L\)'s.

Challenge: if \(L = 1.000 \pm 0.005\) m (0.5%) and \(T = 2.01 \pm 0.02\) s (1.0%), find the percentage uncertainty in \(g\). \(\%\ \text{unc}(g) = \%\ \text{unc}(L) + 2\times\%\ \text{unc}(T) = 0.5\% + 2(1.0\%) = 2.5\%\).

uncertainty = estimated range reading unc. = ½ smallest division %unc = Δx/x × 100 add/sub → sum absolute unc. ×, ÷ → sum fractional/% unc. power n → multiply %unc by n quote to 1 s.f. (2 s.f. if leading digit is 1) Δ(constant) = 0

⚠️ Trap corner – common mistakes

MisconceptionCorrect view
Uncertainty and error mean the same thingError is the actual difference between a reading and the true value, caused by equipment or technique; uncertainty is the estimated range assigned around a reading to allow for that
A longer decimal answer from a calculator is more accurateThe significant figures in the final answer must match the precision of the absolute uncertainty — extra calculator digits carry no real information
Uncertainties should be quoted to as many significant figures as convenientQuote uncertainties to 1 s.f., unless the leading digit is 1, in which case 2 s.f. is allowed
Percentage uncertainties can be added directly for a sum or differencePercentage/fractional uncertainties are only added for multiplication and division; for addition and subtraction, add the absolute uncertainties
⚠️ Most common exam slip: forgetting the power \(n\) when propagating through \(y = a^n\). The rule is \(\Delta y/y = n\times(\Delta a/a)\) — the fractional uncertainty must be multiplied by the power, not just copied across.
